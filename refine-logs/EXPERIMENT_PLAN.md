## B01 冻结策略两两对抗

- 主矩阵使用 8 个随仓库发布的 3m 策略权重，包括 QMIX、VDN、DOP、FOP、QPLEX、COMA、IQL 和 QTRAN。内置 Bot 可另外作为参考行或附表，主矩阵保持学习策略之间相同的控制接口。
- 两边均通过 Agent 读取本方观测和动作掩码、运行冻结策略并输出合法动作。使用 3m 镜像出生、固定动作选择口径、相同游戏版本与时间上限。启动正式矩阵之前，先核对两侧单位数和输入维度、历史动作时间索引、镜像动作及终局判定。
- 每个无序组合使用同一组 144 个预先锁定的出生点，双方各做红方一次。28 个组合预计 8,064 局。可再做 1,152 局同策略自对抗检查阵营偏差。主表对角线标记为自对抗，阵营偏差单列。
- 矩阵单元表示行策略对列策略的胜率，两种阵营方向等权。胜率分母包含平局，表格同时给出胜／负／平及局数。保留每局阵营、出生点、游戏会话种子与实际结局，记录权重、地图和配置指纹。配对的共同单位为出生点，游戏会话种子单独记录。
- **交付与验收**。胜率热力矩阵、胜／负／平明细 CSV、每个策略的等权对手平均和两种阵营结果。每个组合和阵营覆盖齐全，正反单元的胜和负能从同一批记录相互核对。

B01 的双 Agent 互控与历史混合模式使用的红 Agent／蓝 Bot 注入策略，存在单位类型及可见性分支差异。B01 的矩阵和后续复用历史协议的结果分别标注，避免把环境模式差异归因给策略能力。

## B02 训练单对手 VDN，先做 QMIX

- 首组使用原始 VDN 权重初始化，只让红方 VDN 与冻结的蓝方 QMIX 累积训练经验。用 B01 矩阵为后续覆盖面选组。可先选一个不同策略类型和一个表现较强的对手，再按资源扩到全部 8 个。内置 Bot 单训作为额外对照。
- 对照重跑混合对手组，使用相同的 VDN 参数、场景和训练种子，同一函数生成训练、验证和测试出生点。协议统一游戏版本、红蓝角色、8 个采样实例、奖励、Batch 32、5,000 局经验回放和探索／学习率日程。两组训练对手选择不同，验证仍覆盖 8 种冻结算法及 Bot。
- 环境步和 learner 更新次数都控制。当前脚本每收集一批局数做约一半局数的更新。单一对手可能改变局长，按同一环境步数结束时更新次数可能不同。新训练协议拟采用统一的更新／环境步约 1:53，延续 5,000 步预热，并让混合对照使用同一策略。每一配对种子共享初始化权重和出生点划分。
- 最少 200 万环境步，按既有协议每约 10 万环境步做一次冻结验证。每轮每个对手 72 局，共 648 局。保留最近五轮的判据，即总胜率极差 ≤5 个百分点、平均回报极差 ≤1、单对手胜率极差 ≤18 个百分点。未达到判据的运行继续到预设上限 300 万步，再登记实际状态。各组保存 200 万步附近的同预算检查点和验证数据。某组需要更长训练时，主对照使用双方均达到判据的共同训练预算；无法取得共同预算时，保留同预算验证曲线，并标注最终模型的训练步数。
- **扩展判据**。先做 QMIX 与混合对照各一轮配对训练，用共同验证集判断方向与量级。如果整体差小于约 5 个百分点、按验证出生点重抽样的区间跨零，或整体与低胜率对手的结果方向不一致，先补配对训练种子，再决定加哪些对手。正式结论建议以至少 3 个配对训练种子为基础。只有补齐全部单对手组，才判断是否优于每一种单对手训练。
- **交付与验收**。每个训练组的参数、训练步数、更新次数、模型、验证记录和收敛状态。验收只看预登记的验证数据，最终测试样本留到 B03。

## B03 冻结测试及横向比较

1. **共同对手库评估**。将混合训练 VDN、QMIX 单训 VDN 和已验收的其他单训 VDN，与原始 VDN 一起评估。主指标为八种学习对手的等权胜率。辅助指标包括含 Bot 的九对手总胜率、最低三种对手的平均胜率、逐对手胜负平，以及单训组在训练对手和其余七个学习对手上的胜率。主比较使用预先留出的 144 个新出生点，每个种子内按出生点与对手配对。
2. **面板兼容对照**。原批次的箱线图和数据作为归档参照。在新批次用原报告同一套 144 个出生点和冻结规则给单训 VDN 补测，从原始 VDN、历史混合 VDN 到单训 VDN 形成并列系列。新出生点上的配对结果用于正式比较，历史图采用原来的样本。
3. **训练后策略直接对打**。把混合训练 VDN 和每个单训 VDN 冻结，沿用 B01 的双 Agent 与红蓝互换方式。保存胜／负／平及差异。直接对局回答两版 VDN 谁在该设置下更占优势，共同对手库评估回答谁覆盖的对手更广。
4. **表格与图**。结果表包含逐对手胜率、局数、配对胜率差及跨训练种子汇总。箱线图对相同对手和出生点做配对重抽样，保持原图定义。只有单个训练种子时，箱线图反映出生点抽样波动。多训练种子时另外显示各训练种子的指标及配对区间。胜率折线图横轴为环境步，使用相同检查点间隔、评估库和出生点。显示整体等权验证胜率，并支持查看单个对手；探索中的训练对局胜率作为独立诊断。
5. **结论口径**。整体胜率增加且低胜率对手组改善，支持在本固定对手库上的覆盖更全面。某一专长对手局部下降时，同时报告幅度。如果只比较了 QMIX 和少数单训组，结论覆盖已测组。若需要区分 8 个算法的多样性与内置 Bot 暴露，追加不含 Bot 的 8 模型混合训练对照。
