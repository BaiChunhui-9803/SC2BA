# B01 冻结策略两两对抗结果

2026-11-25 在 SC2BA Lab 上完成。启动前和验收后都确认本机没有运行中的 SC2 引擎。两边均为 Agent，使用 3m 镜像出生、SC2 5.0.16.97425 与 8 个仓库原始冻结权重。

- B01a 跑完 16 局，全部 8 个策略均在红蓝两侧出场。核对 384 次移动映射，初始位置完全镜像，动作掩码、前一时刻动作和终局判定通过。
- B01b 在 8 个 SC2 实例上跑完 9,216 局，共 334,370 环境步，耗时 335 秒，重试 0 次。主矩阵包含 8,064 局，另有 1,152 局同策略自对抗。
- 每对策略在相同 144 个预先固定的出生点互换红蓝，共 288 局。正反单元的胜负与平局已按逐局结果复算。

| 策略 | 对其余七种策略等权平均胜率 |
|---|---:|
| QMIX | 54.91% |
| DOP | 48.51% |
| IQL | 46.97% |
| FOP | 39.73% |
| QPLEX | 38.89% |
| QTRAN | 27.18% |
| COMA | 24.60% |
| VDN | 0.89% |

QMIX 对七个对手的胜局均多于负局。主矩阵共有 2,385 局平局，约 29.6%，平局计入胜率分母。自对抗的红蓝胜局最大差出现在 IQL，为 66 比 56，对应 6.9 个百分点。

针对原始 VDN 的 0.89%，用历史混合对抗保存的 36 局红方轨迹复核了 912 个环境步。B01 控制器、历史推理代码和归档动作完全一致。两个批次的蓝方控制和观测协议有差异，B01 的结果对应双 Agent 冻结对抗场景。

## B02a 首对训练与验证

训练种子为 26112503。QMIX 单训与九对手混合训练统一初始化、出生点划分、参数更新频率和稳定判据，两组均在名义 200 万环境步达到判据。实际步数分别为 2,002,384 与 2,001,813。两组为后续留出测试保存了冻结权重。

| 200 万步档验证指标 | QMIX 单训 | 混合训练 |
|---|---:|---:|
| 八种学习对手等权胜率 | 91.15%（525/576） | 91.67%（528/576） |
| 含 Bot 的九对手等权胜率 | 91.05%（590/648） | 92.13%（597/648） |
| 最弱三种学习对手平均胜率 | 87.50% | 86.57% |

主指标的混合组减 QMIX 单训为 +0.52 个百分点，验证出生点配对重抽样的 95% 区间为 [−2.60, +3.47] 个百分点。当前证据来自一个训练种子，按 B02 扩展判据先补配对训练种子。B03 留出测试尚未运行。
